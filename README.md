# se-fe-genel

SE & FE Garaj - Günlük Gelir Gider Defteri

Bu proje, günlük gelir ve gider takibi için hazırlanmış basit bir HTML defteri uygulamasıdır.

## Özellikler

- 25 satırlık günlük kayıt alanı
- Ödeme şekli takibi (Nakit, Kart, Hesap)
- Harcama yapan kişi bilgisi
- Gün başı ve gün sonu bakiye hesaplama
- Yazdırmaya uygun tasarım (A4 tek sayfa)
- Hazırlayan ve onaylayan imza alanları

## Kullanım

`index.html` dosyasını tarayıcınızda açın ve yazdırın (Ctrl+P).
